01 / Design Concepts

三个方向，一条主线

母婴品类的视觉底线是安全感与柔软度：拒绝尖锐直角、拒绝高饱和刺激色、拒绝复杂具象插画。三个方案都建立在 4px 网格与圆角几何之上，区别只在于「品牌想先说哪一句话」。

推荐 · 主标识

A · 心智萌芽 Sprout Mind

一枚温润的「卵形」轮廓代表母体包裹与生命孕育；内部以负形镂空长出双叶新芽，寓意 kids 的心智在安全环境中生长。图形只有「一个外形 + 一个负形」，16px 仍可辨识，是唯一能同时满足图标、Appicon、包装压印的方案。

备选

B · 双心智 Twin Minds

大圆（parent）与小圆（child）交叠，白环分离两层，直接讲述「两颗心同频」。叙事最直白、亲和力最强，适合社群与内容型产品；缺点是双色结构在小尺寸下会糊成一团，需额外做单色简化版。

App 图标专用

C · K 字圆章 Monogram

把首字母 K 做成圆头笔画，右上斜线末端收为一颗圆点（孩子的头），装入圆角方章。识别效率最高、最适合做头像与货架位；但图形语义弱于 A，建议只作为头像位与 App 图标的补充，不与 A 混用。

02 / Logo Construction

标识构造 · 安全区 · 最小尺寸

主标识建立在 64 × 64 单位网格上，所有圆角与笔画均为 4 的倍数。负形芽体居中偏移 0，保证旋转对称的视觉稳定。

构造网格

外形 = 卵形（孕育 / 包裹）；芽体 = 负形镂空（心智生长）。二者共用同一条视觉中轴。

安全区 Clear Space

标识四周必须保留不小于标识宽度 1/4 的留白，任何文字、图形、裁切线不得进入。

03 / Color System

色彩系统

母婴品类避免使用正红与荧光色。主色取「肌肤暖粉 → 暖阳杏」的渐变，传递体温与拥抱；薄荷绿作为成长/安心辅助色仅用于点缀与状态反馈，不承载大面积正文。

04 / Typography

字体

字标全部小写 —— 小写字母圆润、无锐利竖线，天然降低压迫感，符合母婴语境。

单色标识在深底使用反白版、浅底使用 Soft Ink 版，保证标识本身 ≥ 3:1。所有可点击的标识需具备 focus-visible 焦点环。

SVG 使用要点

作为图标使用时补齐可访问属性：

<svg role="img" aria-label="kids mind"
     focusable="false"> … </svg>

/* 装饰性出现时 */
<svg aria-hidden="true" focusable="false">

单色版使用 fill="currentColor"，颜色由外层 CSS 控制，深浅色主题自动适配。
