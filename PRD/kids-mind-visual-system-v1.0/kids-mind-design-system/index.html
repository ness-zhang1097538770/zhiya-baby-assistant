10 / Motion

动效规范

所有动效仅使用 transform / opacity，避免触发重排；支持 prefers-reduced-motion 降级。

卡片悬停上浮

translateY(-3px) + shadow-md · 250ms ease-out

按钮按下反馈

scale(0.97) · 150ms ease-out

图片加载淡入

opacity 0→1 · 300ms

骨架屏闪烁

background-position 动画 · 1.5s infinite

场景时长曲线属性
微交互（按钮、图标）150mscubic-bezier(0.16,1,0.3,1)transform / opacity
卡片 / 列表进场250mscubic-bezier(0.16,1,0.3,1)translateY + opacity
弹窗（桌面缩放 / 移动上滑）250mscubic-bezier(0.16,1,0.3,1)scale / translateY + opacity
Toast 进出200mscubic-bezier(0.16,1,0.3,1)translateY + opacity
AI 流式回答逐字——文本节点逐个 append，光标 blink 1s

prefers-reduced-motion 降级

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
11 / Accessibility & Adaptation

无障碍与适配

对比度

正文 Ink #2A3633 / 白底 12.9:1（AAA）。医疗风险色配图标冗余，色盲可辨。

焦点环

所有可交互元素使用 outline: 2px solid var(--km-ink); outline-offset: 3px;。

点击热区

移动端图标按钮 ≥ 44×44px；底部导航 ≥ 48px 高度。

表单错误

使用文案 + 图标 + 红色边框，不能仅依赖颜色。

断点

390（移动基准）、768（平板）、1280（桌面内容区）、1440+（大屏）。

深色模式

当前版本暂不支持。Token 命名已预留 dark 变体，后续可扩展，不影响当前浅色实现。

12 / Design Decisions

关键设计决策回应

关于现有 Token 的处理

  • 标题宋体：改为思源黑体 / 阿里巴巴普惠体，避免 Windows 降级 SimSun。
  • 深绿 #173c36：调整为更柔和的 Soft Ink #2A3633，与暖色卡片对比仍成立但不再刺眼。
  • 卡片密度：统一内边距 16–24px，卡片间距 16–24px，区块间距 32–48px。
  • 橙陶土主色：沿用并刷新为 #D86B4C，与 Logo 渐变协调。

关于品牌与产品气质

  • Logo 使用已确认的「心智萌芽」图形 + lowercase 字标。
  • 整体视觉「专业可信、温柔不幼稚」，避免卡通化。
  • 医疗风险使用独立色板 + 图标冗余，确保安全合规。
  • AI 免责声明固定样式，所有回答卡片底部强制出现。
