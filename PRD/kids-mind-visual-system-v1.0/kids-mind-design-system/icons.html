05 / Iconography

图标库

24px 线性图标，2px 描边，圆角端点与圆角连接。所有图标基于同一套视觉语法绘制，可直接作为 SVG Sprite 使用。

技术规范

  • 画布：24×24，关键图形居于 20×20 安全区内。
  • 描边：2px，stroke-linecap/linejoin 均为 round。
  • 颜色：使用 currentColor，外层 CSS 控制。
  • 使用方式：<svg><use href="assets/icons.svg#icon-home"></use></svg>
