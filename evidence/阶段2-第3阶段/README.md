# 证据包｜阶段 2 后端 MVP 第 3 阶段（故事工坊：大纲 + 正文 + 插画 + 朗读 + 书架）

## 你能自己打开验证的地址

浏览器打开：**http://localhost:8001**（服务已启动）

## 照着点（验收步骤）

1. 打开页面，选中一个儿童。
2. **⑥ 故事工坊**：填角色名（如"小糯米"）、主题（如"刷牙"）→ 点"生成大纲"。
3. 等约 5-10 秒看到 8-12 页大纲（可改）→ 点"确认，生成正文"。
4. 等约 10-20 秒看到每页正文 → 点"生成插画和朗读"。
5. 等约 3-5 分钟（插画有分钟级限流），看到每页**插画图 + 可播放的朗读音频**。
6. 下方"书架"出现故事，可点"查看"。

## 真实冒烟结果（真实模型 + 真实硅基流动）

- 故事《小糯米的小牙刷》：10 页，大纲 6.1s、正文 10.1s
- 插画：10 张（Kwai-Kolors/Kolors，3:4 竖版），约 4 分钟（受分钟级限流影响）
- 朗读：10 段 mp3（CosyVoice2-0.5B）
