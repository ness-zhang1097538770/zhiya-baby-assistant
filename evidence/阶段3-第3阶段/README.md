## 你照着点
1. 电脑浏览器打开 <http://localhost:3001/growth>（后端用 `./start.sh` 启动）。
2. 顶部下拉框切换孩子；默认「时间线」按日期回看记录，顶部筛选条可只看某一类。
3. 点「记一笔」，选类型填内容保存：喂养填奶量、身高体重填数值、里程碑填标题，保存后时间线立即出现。
4. 点记录右侧的**铅笔**编辑、**垃圾桶**删除（会弹确认）。
5. 切到「提醒」标签页，点「添加提醒」建一条疫苗提醒；用右边的**开关**启用/停用，铅笔/垃圾桶编辑/删除。
6. 把窗口拉窄到手机宽度，底部导航和筛选条可用，页面不左右滑动。

## 看到什么算对
- 时间线按日期倒序分组（今天/昨天/具体日期），记录类型图标 + 摘要 + 备注 + 时间齐全。
- 新建/编辑/删除后，列表与时间线立即同步刷新。
- 提醒开关能实时停用（条目变灰），删除有二次确认。
- 首页的快捷记录卡片（喂养/睡眠/身高体重/里程碑）点击后直达对应记录表单。
