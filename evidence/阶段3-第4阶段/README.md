# 阶段 3 · 第 4 阶段验收

> App 封装 + 到点响铃提醒（安卓内测包）

## 已交付
- 安卓安装包：[kidsmind-v1.0-android-debug.apk](./kidsmind-v1.0-android-debug.apk)（4.0MB，内测版）
- 安装与验证步骤见下方。

## 先说清楚（重要）
- 这是**安卓内测包**，App 里跑的页面来自你电脑上的开发服务器。所以：
  - 手机和电脑要连**同一个 WiFi**；
  - 电脑上要先跑 `./start.sh`（后端 8001 + 前端 3001 都起来）；
  - 电脑 IP 如果变了，需要改 `frontend/capacitor.config.ts` 里的地址后重新打一次包。
- 提醒是**手机系统本地通知**：到点会像闹钟一样弹提醒 + 响铃，App 关掉、锁屏也会响（需允许通知权限）。

## 安装到安卓手机（照着做）
1. 把 `kidsmind-v1.0-android-debug.apk` 发到手机：微信「文件传输助手」发过去，或数据线拷贝。
2. 手机上点这个 apk 文件；若提示「禁止安装未知来源」，按提示允许本来源后继续。
3. 安装完成后打开 **Kids Mind**（图标是默认的）。
4. 首次打开会加载电脑上的页面（需要同一 WiFi + `./start.sh` 已启动）。

## 验证「到点响铃」（照着做）
1. 进入「成长 → 提醒」，点「添加提醒」，填一条提醒，时间设成**1-2 分钟后**。
2. 保存时系统会弹「允许 Kids Mind 发送通知」，点**允许**。
3. 关掉 App（或锁屏）等 1-2 分钟。
4. 到点后手机应弹通知 + 响铃。

## 看到什么算对
- 到点手机弹出通知、有声音，点通知能回到 Kids Mind 提醒页。
- 把提醒**停用**后，到点不再响；**删除**后也不响。
- 关掉 App、锁屏，通知依然按时到（本地闹钟由系统触发）。
