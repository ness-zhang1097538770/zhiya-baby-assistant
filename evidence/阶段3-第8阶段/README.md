# 阶段3-第8阶段：问育儿医疗大模型通道（百川 M3-Plus）验收说明

## 这个阶段做了什么

给「问育儿」接入了医疗大模型（百川 M3-Plus），按问题自动分流：

| 问题类型 | 走哪个模型 | 举例 |
| --- | --- | --- |
| 医疗类（发烧/咳嗽/腹泻/用药/疫苗/就医…） | 百川 M3-Plus | "宝宝咳嗽三天要吃药吗" |
| 其他育儿类（喂养/睡眠/早教/绘本…） | DeepSeek（照旧） | "8 个月辅食怎么加" |
| 危急情况（抽搐/窒息/脱水…） | 确定性代码秒回急救提示（不交给模型） | "宝宝突然抽搐怎么办" |

安全兜底：百川调用失败会自动退回 DeepSeek，绝不出现"答不出来"；提问只存哈希不落明文。

当前**已放量到全部内测用户**（MEDICAL_ROLLOUT_PERCENT=100）：所有孩子的医疗类问题都走百川，其他育儿问题照旧走 DeepSeek。

## 照着点验收（约 3 分钟）

1. 打开 `http://localhost:3001/ask`（服务已在跑；若没跑，先执行项目根目录 `./start.sh`）
2. 用邀请码 `A5CS7VCX` 登录
3. 右上角「切换孩子」任选一个孩子
4. 输入框问一句医疗问题，例如：**「宝宝咳嗽三天了，需要吃药吗？」**，点发送
   - 预期：返回带循证依据的回答（引用了知识库来源），不是"请咨询医生"一句话敷衍
5. 再问一句非医疗问题，例如：**「8 个月宝宝辅食应该怎么加」**
   - 预期：正常返回辅食建议（和之前一样）
6. （可选）切到其他孩子问同样的医疗问题，观察回答是否结合孩子月龄个性化
