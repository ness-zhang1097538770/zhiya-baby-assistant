## 你照着点
1. 电脑浏览器打开 <http://localhost:3001/ask>（后端已用 `./start.sh` 启动时直接可看；没启动就先 `./start.sh`）。
2. 顶部下拉框切换孩子，左侧/顶部是「历史会话」列表，点「新提问」开新对话。
3. 在底部输入框输入 `8 个月辅食加什么` 回车，看答案**逐段流式出现**，结束后带「常规」徽标和「参考来源」。
4. 再输入 `宝宝突然抽搐怎么办`，应立即秒回「危急」急救提示（含拨打 120），**不会等模型**。
5. 刷新页面，刚才的会话仍在「历史会话」列表里，点开能看到之前的问答。
6. 把窗口拉窄到手机宽度，历史会话折叠为顶部下拉框，底部导航和输入框仍可用，页面不左右滑动。

## 看到什么算对
- 输入常规问题后，助手气泡先出现"正在组织回答"，随后答案逐段出现，不是一次性整块弹出。
- 危急问题秒回急救提示，无等待、无来源引用。
- 常规答案带「结论 / 可以这么做 / 依据 / 出现这些情况请就医 / 免责声明」结构 + 参考来源。
- 刷新后历史仍在；切换孩子后看到的是对应孩子的会话。

## 真实模型冒烟记录（已跑通）
- L1 危急「宝宝突然抽搐怎么办」：秒回，含 120 急救提示，未调用模型（后端日志确认无模型请求）。
- L4 常规「8 个月宝宝辅食应该怎么加」：真实 DeepSeek deepseek-flash 流式返回 51 个 chunk + 1 个 done，风险 L4，9 条建议，2 条来源，含免责声明。
- 会话历史：新会话（id 24）刷新后可恢复，用户消息 + 助手消息（含风险级、来源）完整持久化。
