# 证据包｜阶段 2 后端 MVP 第 2 阶段（成长记录 + 提醒 + 时间线）

## 你能自己打开验证的地址

浏览器打开：**http://localhost:8001**（服务已启动）

## 照着点（验收步骤）

1. 打开页面，选中一个儿童（或新建一个，会自动选中）。
2. **成长记录**：在"③ 成长记录"选类型（如"喂养"）、填备注（如"母乳 120ml"），点"保存记录"。
3. **时间线**：在"④ 时间线"看到刚存的记录，按日期倒序排列；切换类型下拉框可筛选。
4. **提醒**：在"⑤ 提醒"选类型（如"疫苗"）、填内容（如"打疫苗"）、填时间（如 `2026-09-20 10:00`），点"新增提醒"，下方出现提醒；点"删除"可删。
5. 重启后数据仍在（我已实测：2 条事件、1 条提醒重启后都在）。
