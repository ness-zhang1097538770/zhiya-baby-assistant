# 证据包｜阶段 2 后端 MVP 第 1 阶段（儿童档案 + 育儿问答）

## 你能自己打开验证的地址

启动方式（我先帮你起好，或你自己起）：

```bash
cd docs/母婴育儿多智能体开发/backend
.venv/bin/uvicorn app.main:app --port 8001
```

浏览器打开：**http://localhost:8001**（手机也能打开，做了移动端适配）

## 照着点（验收步骤）

1. **建档**：在"① 新建儿童档案"里填昵称（如"小糯米"）、出生日期（如 2026-01-16），点"创建档案"；下方出现一个可点选的儿童标签。
2. **选儿童**：点一下那个儿童标签（变蓝即选中）。
3. **常规问答**：在"② 育儿问答"输入框输入"8个月的宝宝辅食可以加什么？"，点"提问"，等 5 秒左右，看到答案逐字出现，含【结论】【可以这么做】【依据】【何时就医】【免责声明】和📚来源。
4. **危急问答**：输入"宝宝突然抽搐怎么办"，点"提问"，**立即**（不等模型）弹出急救提示 + 120。
5. **看历史**：同一会话里继续问一句，能看到上下文衔接。
