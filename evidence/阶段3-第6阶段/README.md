## 你照着点
1. 电脑浏览器打开 <http://localhost:3001/profile>（后端用 `./start.sh` 启动）。
2. 看「家里的孩子们」：列出你建档的所有孩子（昵称、月龄、性别、喂养方式）。
3. 点「添加孩子」能建档。
4. 往下看「隐私与数据」「关于」两个板块。
5. 把窗口拉窄到手机宽度，看排版是否正常、不左右滑动。

## 看到什么算对
- 儿童档案列表真实来自后端（和首页切换的孩子一致）。
- 隐私与数据、关于、免责声明文案完整。
- 底部导航「我的」高亮，页面无横向溢出。
