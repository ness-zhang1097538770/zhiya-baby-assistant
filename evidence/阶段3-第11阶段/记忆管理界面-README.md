## 3. 产品经理「照着点」验证步骤

1. 项目文件夹下 `./start.sh`（已启动）。
2. 打开 http://localhost:3001，用邀请码登录（如 `A5CS7VCX`）。
3. 首页一句话输入框输入 **「宝宝对花生过敏，帮我记一下」** → 走起。
4. 点底部导航「我的」，选中同一个孩子，向下滑到 **「育儿管家记忆 · AI 帮你记住的」**：
   - 应看到一条「过敏 花生：过敏」，带「AI 提取」小字。
   - 点铅笔图标改内容 → 保存 → 立即生效。
   - 点垃圾桶图标 → 确认删除 → 该条消失。

## 4. 重点看什么

- 记忆是否准确列出（过敏这类敏感事实要记对）。
- 编辑/删除是否即时生效、刷新后仍一致（数据落库）。
- 不同孩子之间记忆是否隔离（切孩子后看到的是各自的事实）。
