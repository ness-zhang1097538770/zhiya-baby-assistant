# 阶段 3-第 11 阶段：育儿管家最小闭环 — 证据包

> 一句话入口 → 直接执行 + 记忆抽取

## 1. 本阶段做了什么

把首页「一句话入口」从「只分类 + 跳转」升级为「分类 + 直接执行 + 记忆抽取」：

- 说「记下 / 提醒 / 记住 / 讲故事」这类话 → 系统**直接替你办**（记录、设提醒、记事实），并在首页内联展示结果。
- 说「怎么办 / 吃什么」这类问题 → 仍跳转到问育儿页（复用已有 CARE 答案 + 风险分级 + 医疗路由）。
- 「生成故事」→ 先弹「去创作」确认（有模型费用），再进故事工坊。

## 2. 真实模型冒烟（DeepSeek deepseek-flash，已跑通）

见同目录 `真实冒烟记录.txt`。四条用例全部符合预期：

| 输入 | 结果 |
| --- | --- |
| 宝宝对鸡蛋过敏，帮我记一下 | ✅ 记忆抽取：已记住[过敏] 鸡蛋：过敏（source=ai_extract，可改可删） |
| 记下宝宝刚喝了150ml奶，再定个2小时后的喂奶提醒 | ✅ 一句话两动作：已记录喂养 + 已创建提醒（13:23） |

冒烟脚本（可复现）：`冒烟脚本.py`（隔离临时库，不污染真实数据）。

## 3. 产品经理「照着点」验证步骤

1. 项目文件夹下执行 `./start.sh`（后端已重启，会加载新接口）。
2. 浏览器打开 `http://localhost:3001`，用邀请码登录（如 `A5CS7VCX`）。
3. 选一个孩子，在首页顶部「说一句话，我来帮你办」输入框里：
   - 输入 **「宝宝对鸡蛋过敏，帮我记一下」** → 点「走起」→ 应看到内联结果「已记住[过敏] 鸡蛋：过敏」。
   - 输入 **「记下宝宝刚喝了150ml奶，再定个2小时后的喂奶提醒」** → 应看到两条结果（已记录喂养 + 已创建提醒）。
   - 输入 **「给宝宝讲个勇敢小恐龙的故事」** → 应看到「生成绘本故事：勇敢的小恐龙」+「去创作」按钮，点了跳到故事工坊。
   - 输入 **「8个月宝宝辅食吃什么」** → 应跳到问育儿页并自动填好问题。
4. 去「成长」页看时间线，应能看到刚记录的那条喂养；「提醒」里应有刚建的提醒。

## 4. 验证时重点看什么

- 记忆抽取是否准确（过敏这类敏感事实要记对）。
- 一句话多动作是否都办了。
- 生成故事是否先确认、再跳故事页（没直接花钱生成）。
- 问答是否仍走原来的问育儿页（没在入口重复造）。
