# Agent Loop — 证据包（阶段 3-第 11 阶段补充）

> 给育儿管家加上 s01 的「受控循环」：规划 → 执行 → 复查补全；信息不足时追问。

## 1. 做了什么

- **后端**：`run_agent` 从单轮升级为受控循环——
  - 首轮规划 → 执行（白名单 + 去重）→ 把结果喂回模型「复查是否还有遗漏」→ 补办，**硬上限 2 轮**（防死循环/烧钱）。
  - 新增意图 `need_info`：信息不足时不瞎办，返回 `followup_question` 交给前端追问。
- **前端**：「一句话入口」支持就地追问——显示追问问题，家长补充后自动拼接上下文重新提交。

## 2. 验证结果

- 后端 **118/118**（新增 test_agent_loop.py 6 例：追问不执行、复查补全、done 停止、去重、复查失败兜底、API 返回追问）。
- 前端 **13/13** + tsc / eslint 全过。
- 真实 DeepSeek 冒烟：
  - 「记一下」→ 追问「要记什么内容呢？」
  - 「设个提醒」→ 追问「要提醒你做什么事呢？」
  - 「记下喝了150ml奶，再定个2小时后喂奶提醒」→ 两动作全办。

## 3. 产品经理「照着点」验证

1. `./start.sh`（已启动），打开 http://localhost:3001 登录。
2. 首页一句话输入框输 **「记一下」** → 走起 → 应看到追问「要记什么内容呢？」，输入框变「补充一下」。
3. 输入 **「喝了150ml奶」** → 补充 → 应看到「已记录喂养」。
4. 再试 **「记下喝了150ml奶，再定个2小时后喂奶提醒」** → 应一次看到两条（记录 + 提醒）。

## 4. 重点看什么

- 信息不足时会不会「瞎办」还是「先问」（安全）。
- 追问后补充，能不能把事办成（闭环）。
- 一句话多个动作是否都办到（不漏）。
