# 阶段3-第9阶段：故事工坊多 Agent 协作（第一步）验收说明

## 这个阶段做了什么

把故事工坊从"两步确认"升级为**多 Agent 分步协作**，每一步都停下来问你意见（按你选的 A）。

| 步骤 | Agent | 做什么 | 是否停 |
| --- | --- | --- | --- |
| 第一步 | 角色 Agent | 设计主角、配角、整体画风 | ✅ 停下等你确认/修改 |
| 第二步 | 剧本 Agent | 写故事大纲（标题 + 每页场景） | ✅ 停下等你确认/修改 |
| 第三步 | 导演 Agent | 把大纲扩写成分页正文 + 画面描述 | ✅ 停下等你确认 |
| 收尾 | （自动） | 生成插画 + 朗读 | 自动 |

背后是同一套模型扮演不同角色（省钱），但体验上就是"不同角色在协作、每步可提意见"。

> 照片生成角色（第二个需求）按约定**第二步再做**，本阶段未包含。

## 照着点验收（约 3 分钟）

1. 打开 `http://localhost:3001/stories/13`（这是一本已停在「第一步」的测试绘本，主角是小糯米）
   - 应看到「第一步 · 确认绘本角色」：主角"小糯米"的外貌/性格、配角"鹿鹿"和"啾啾"、整体画风，都能改
2. 改一下某个字段（比如把主角外貌改一改），点「确认并生成故事大纲」
   - 应进入「第二步 · 确认故事大纲」，看到 11 页大纲
3. 点「确认并生成正文」，可继续走到正文和插画（插画生成约几分钟，可略过）
4. 也可以自己新建一本：书架 → 创作故事 → 填主题 → 创建后先看到角色设计
