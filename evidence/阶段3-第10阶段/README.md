# 阶段3-第10阶段：上传孩子照片生成绘本角色 验收说明

## 这个阶段做了什么

在故事工坊「创作故事」里加了**上传孩子照片（可选）**：AI 用照片生成绘本角色形象，之后照常一步步生成故事。

流程：上传照片 → AI 转成绘本卡通角色形象 → 角色 Agent 设计角色 → 剧本 → 正文 → 插画朗读。

## 隐私说明（重点）

- 孩子照片**只在内存里处理一次，从不落盘**，转出卡通角色图后立即丢弃原照片；
- 只保留**卡通角色形象图**（不是孩子真实照片）；
- 不传照片也完全能用（照片是可选步骤），保留了原有流程。

## 照着点验收（约 3 分钟）

1. 打开 `http://localhost:3001/stories`，点「创作故事」
2. 填好主题等，点 **「上传照片生成角色」**，选一张孩子照片（手机里的照片即可）
   - 稍等几十秒，会显示生成的**卡通角色形象预览**
3. 点「开始创作」→ 进入「第一步 · 确认绘本角色」
   - 能看到卡通角色形象图 + 可编辑的主角/配角设定
4. 确认角色 → 大纲 → 正文（和之前多 Agent 流程一致）

> 测试说明：我用一张模拟图走通了完整链路（上传→转卡通→角色生成）。真实孩子照片的效果需要你用自家照片验证一次。

## 冒烟证据

- `真实冒烟记录.txt`：完整 HTTP 链路（上传照片 → 转卡通角色形象 → 创建故事带角色形象 → 角色 Agent 生成，风格与卡通图一致）。

## 本次改动范围

- 后端：`media.generate_character_image`（Qwen-Image-Edit 图生图，照片转绘本卡通角色）；Story 模型加 `character_image` 字段；`POST /stories/photo` 上传接口（10MB 上限、真实类型校验、原照片不落盘）；StoryCreate 支持 `character_image`。
- 前端：创作表单加「上传照片生成角色」（可选）+ 预览；角色确认页展示角色形象图。
- 测试：后端 82/82（新增照片上传 + 带角色形象创建用例），前端 13/13 + 类型检查 + Lint 全过。
