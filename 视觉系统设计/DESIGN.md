# Kids Mind 视觉系统设计（DESIGN.md）

**产品**：Kids Mind · 面向 0-6 岁儿童家长的科学育儿助手（育儿问答 / 成长记录 / 提醒 / AI 故事 / 陪伴建议）
**读者**：设计部（交付方）与前端（落地方）
**版本**：v1.1 ｜ **语言**：zh-CN ｜ **基线来源**：`视觉系统设计需求清单 v1.0`

**本次任务范围**：把需求清单转化为一套可落地、可验证的设计系统（Token + 组件 + 页面规则），并答复清单第十二节的待确认事项。

**已提供的证据**
- 需求清单 docx / md（D1-D10 交付物、现状基线、风险分级、图标清单、验收标准）
- `frontend/app/globals.css`（593 行，现有 Token 与六页样式）、`frontend/package.json`（Next 16 + Tailwind v4 + React 19 + lucide-react 0.468.0）
- 本机实算的 WCAG 对比度（WCAG 2.x 相对亮度公式，结果见第 2 章与附录 C）

**影响结论的关键假设**（如与事实不符需回退重判）
1. 首期以浅色模式上线，深色模式不在 P0 范围。
2. 故事配图由 AI 生成，设计部交付风格基准卡而非固定素材库。
3. 中文字体允许自托管 + 子集化（否则需改为纯系统字体栈，第 3 章给出该降级路径）。
4. 桌面 1440 / 移动 390 为设计基准，与需求清单一致。

## 1. 视觉主题

### 1.1 路线决策

分支：**product（产品）**，系统深度 = 全量 Token + 组件级；品牌/平面只处理 D1 标识与 D6 插画风格基准两块，不另起品牌分支。

**主线视觉谱系**：「暖米纸感 + 墨绿容器 + 陶土橙行动色」——**一条**，不设第二谱系。
唯一的辅助手段是「衬线字用于阅读型标题」，它解决的是语气问题（温柔 / 可信），不是新增风格。**不应复制**：可爱卡通风的圆润几何、高饱和糖果色、渐变玻璃拟态——这三样都会直接破坏"专业可信"的医疗安全语境。

### 1.2 层级与密度

| 层级 | 载体 | 表现手段 |
| --- | --- | --- |
| L0 品牌 | 侧边栏品牌区、登录页 | 陶土橙品牌块 + 特征圆角（20/20/20/7） |
| L1 页面 | H1（衬线 32px） | 唯一页面主标题，每页一个 |
| L2 区块 | H2（黑体 22px）+ 计数徽标 | 卡片标题，安静于页面标题 |
| L3 内容 | 卡片（--radius-md / --shadow-soft） | 卡片是本品核心容器 |
| L4 元信息 | Caption 12px / Micro 11px | 时间、单位、来源，永不承载操作说明 |
| L5 强调 | 主按钮 --primary-700、风险竖条 | 全站唯一行动色 / 风险专用 |

**密度是有意图的**：首页是**扫描型**（三档密度：概览区一屏内收、列表区行高 64px、快捷区 4 宫格），问育儿与故事详情是**阅读型**（行宽 ≤ 640px、行高 1.8）。两者不共用一套密度。

### 1.3 与现有基线的关系

现状三色**沿用并调整**，不整体替换。逐项结论见第 7 章对照表。一句话总结：调性保留，数值修正——修正的是三处不达 WCAG AA 的值和一处跨平台字体降级，不是审美方向。

### 2.5 风险分级色（本产品特有）

风险分级与语义色**物理隔离**：不同色阶、不同载体、不同图形。这是避免"红色既表示删除失败又表示需就医"的唯一可靠做法。

| 等级 | 文案 | 底 | 文字 | 描边 | 竖条 | 徽标 | 图标 | 对比度 | 底纹灰度 L* |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| L1 高危 | 建议就医 | `#F7CFC8` | `#8F2A20` | `#D98C82` | 4px 实心 | 实心 | 八角感叹 | 5.84:1 | 86.3 |
| L2 中危 | 居家观察 | `#F8E2B8` | `#7E4606` | `#E3B673` | 4px 实心 | 描边 | 三角感叹 | 5.99:1 | 90.7 |
| L3 常规 | 常规建议 | `#EDF5F0` | `#2F5C4E` | `#B4D3C6` | 2px 实心 | 描边 | 圆形勾 | 6.85:1 | 95.8 |
| L4 声明 | 建议不能替代专业诊疗 | `#F1F0EA` | `#5A6660` | `#C9C6BB` 虚线 | 无 | 虚线 | 盾牌 | 5.25:1 | 94.7 |

**四重冗余编码（色觉障碍与灰度打印可辨）**：色相 + 左侧竖条墨量（4px / 4px / 2px / 无）+ 徽标形状（实心 / 描边 / 描边 / 虚线）+ 固定文案（"建议就医" / "居家观察" / "常规建议"）。去掉颜色后，仅凭竖条粗细、图标形状与文字即可判定等级；底纹明度也逐级拉开 ≥ 4 个 L*。

L4 是固定合规声明，不是等级，始终与 L1-L3 之一同时出现，用虚线框 + 盾牌图标区分，不与前三者做并列比较。

```css
/* 风险卡：四重冗余，去掉颜色仍可辨 */
.risk-card { position: relative; border-radius: var(--radius-md); padding: 18px 20px 18px 24px; }
.risk-card::before { content: ""; position: absolute; left: 0; top: 0; bottom: 0; background: var(--risk-bar); }
.risk-1 { background: var(--risk-1-bg); border: 1px solid var(--risk-1-border); color: var(--risk-1-text); }
.risk-1::before { width: 4px; }
.risk-2 { background: var(--risk-2-bg); border: 1px solid var(--risk-2-border); color: var(--risk-2-text); }
.risk-2::before { width: 4px; }
.risk-3 { background: var(--risk-3-bg); border: 1px solid var(--risk-3-border); color: var(--risk-3-text); }
.risk-3::before { width: 2px; }
```

## 3. 字体系统

### 3.1 字体栈与授权

| 角色 | 字体 | 授权 | 交付要求 |
| --- | --- | --- | --- |
| UI 正文 / 控件 / 导航 | Inter + 系统中文黑体（PingFang SC / HarmonyOS Sans / 微软雅黑） | Inter：SIL OFL 1.1；中文走系统字体，无授权成本 | 仅 Latin 子集 WOFF2（约 30KB），`font-display: swap` |
| 标题 / 阅读型文本 | 思源宋体 Source Han Serif SC（Noto Serif SC 同源） | SIL OFL 1.1，可商用、允许子集化与自托管 | 2 个字重（600/700），常用 3500 字 + 标题用字子集，WOFF2 |
| 数字 / 日期 / 测量值 | Inter + `font-variant-numeric: tabular-nums` | 同上 | 与 UI 正文同包 |

```css
--font-sans: "Inter", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif;
/* 衬线栈末尾接无衬线：Windows 不会降级成 SimSun，而是干净地落到黑体 */
--font-serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", "Inter", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

**宋体问题结论**：不保留 `Songti SC` 作为声明字体。它在 Windows 上不存在，会落到 SimSun（衬线字形与设计意图差异大）。新栈的兜底顺序保证：Webfont 加载成功 → 思源宋体；加载失败 → 无衬线黑体（mac 与 Windows 观感一致），**永不落到 SimSun**。

**降级路径**（若不允许自托管字体）：标题改用 `--font-sans` + 字重 600/700 + 字阶拉开层级，其余规范不变；此时 H1/Display 与正文同族，靠字重与字号区分，视觉损失可接受但"温柔"语气减弱。

### 3.2 字阶表

| 层级 | 桌面 1280-1440 | 移动 390 | 字重 | 行高 | 字体 | 使用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| Display | clamp(32px, 4.2vw, 46px) | 32px | 600 | 1.2 | 衬线 | 登录页品牌名、空状态大标题 |
| H1 | clamp(24px, 2.2vw, 32px) | 24px | 600 | 1.3 | 衬线 | 页面主标题（每页一个） |
| H2 | clamp(19px, 1.5vw, 22px) | 19px | 600 | 1.35 | 黑体 | 卡片区块标题 |
| H3 | 17px | 16px | 600 | 1.45 | 黑体 | 列表项标题、弹窗标题 |
| H4 | 15px | 15px | 600 | 1.5 | 黑体 | 表单分组、卡片小标题 |
| Body-lg | 15px | 16px | 400 | 1.8 | 黑体 | AI 长文、故事正文 |
| Body | 14px | 15px | 400 | 1.7 | 黑体 | UI 正文 |
| Body-sm | 13px | 14px | 400 | 1.6 | 黑体 | 卡片正文、辅助说明 |
| Caption | 12px | 12px | 500 | 1.55 | 黑体 | 时间、单位、来源 |
| Micro | 11px | 11px | 600 | 1.5 | 黑体 | **全站最小字号下限**，仅角标与免责小字 |
| Eyebrow | 11px | 11px | 800 | 1.2 | 黑体 | 仅拉丁短语 TODAY / GROWTH，大写 + 字距 .08em |
| Numerals | 28px | 26px | 600 | 1.2 | Inter tabular | 身高体重、月龄、进度 |

**排版约束**
- 中文字距恒为 `0`；仅拉丁全大写 Eyebrow 使用 `.08em`，中文小标签不拉开字距。
- 移动端断点采用**离散角色切换**，不用连续 `clamp()` 缩放（避免 390-430px 区间字号抖动）。
- 标题换行用 `text-wrap: balance`（仅短标题），长标题自然换行，禁止硬编码 `<br>`。
- 列表与卡片标题超长：主标题换行，副标题单行省略（`text-overflow: ellipsis`），单位与状态永不省略。

**长文阅读版式**：行宽上限 `--measure-reading: 640px`（16px 中文约 42 字/行），行高 1.8，段间距 14px，小标题上间距 24px。AI 回答与故事正文共用此版式。

### 3.3 图标（D4）

- 库：**沿用项目已装的 `lucide-react` 0.468.0**（ISC 许可，可商用），不引入第二套图标库。
- 规格：24px 网格、stroke 2、圆角端点（`stroke-linecap: round`）、单色线性；**不做双色、不做填充混用**。
- 尺寸：默认 24px，内嵌 18px，小尺寸 16px（必要时简化笔画，不缩放描边）。
- 三态：默认 `--ink-soft` / 激活 `--primary-800` / 禁用 `--icon-muted`（3.55:1，禁用态仍须可辨）。
- 图标按钮必须带 `aria-label`；纯装饰图标 `aria-hidden`。

## 4. 组件样式

所有组件统一：六态（默认 / 悬停 / 按下 / 聚焦 / 禁用 / 加载中）+ 错误态文案版式；触摸热区 ≥ 44×44px。

### 4.1 按钮

| 类型 | 尺寸（min-height） | 默认 | 悬停 | 按下 | 禁用 |
| --- | --- | --- | --- | --- | --- |
| 主按钮 | S 32 / M 42 / L 50 | `--primary-700` + 白字 | `--primary-800` + translateY(-1px) | `#8E4526` + scale(.985) | `--primary-200` 底，opacity .7 |
| 次级 | 同上 | `--surface` + `--line-strong` 描边 | `--surface-soft` | `--surface-sunken` | `--surface-soft` + `--muted` 文字 |
| 文字 | 同上 | `--primary-800` 文字 | `--primary-50` 底 | 文字 opacity .8 | `--icon-muted` |
| 危险 | 同上 | `--danger-bg` + `--danger-text` | `#F7D6D0` | `#F5C7BF` | opacity .55 |
| 图标按钮 | 42×42 | `--surface` + 描边 | hover 底 | 凹陷底 | 描边转 `--line` |

聚焦统一：`box-shadow: var(--focus-ring)`（3px / rgba(180,85,47,.30)），深色容器用 `--focus-ring-inverse`。加载中：文字透明 + 16px 旋转指示器，`pointer-events: none`，保留原尺寸不跳动。


### 4.2 输入与选择

- 单行/多行：高 46px（移动 48px）、圆角 `--radius-sm`、描边 `--line-strong`、聚焦主色描边 + 焦点环。
- **移动端输入文本 ≥ 16px**（iOS 聚焦时 <16px 会触发页面缩放）。
- 错误态：红描边 + 警示图标 + 具体文案（说明字段、原因、下一步），**不得只靠颜色**。
- 禁用态：`--surface-sunken` 底 + `--line` 描边 + `--muted` 文字（仍可辨，不是"变淡到看不见"）。
- 开关：46×28，开态 `--sage-700`（不用浅绿，浅绿过淡无法表达"开启"），关态 `#CFCFC8`，禁用 opacity .5。
- 上传（头像）：1:1 裁切，`object-fit: cover`，默认占位见 4.5。

### 4.3 徽标 Badge

| 类型 | 形态 | 规范 |
| --- | --- | --- |
| 风险等级 | 实心 / 描边 / 虚线三种 | 见 2.5，必须带文字 |
| 任务状态 | 描边 pill | 待完成 `--surface-soft` / 已完成 `--sage-100` / 逾期 `--danger-bg` |
| 年龄段 | pill | `--cream-100` 底 + `--cream-700` 字 |
| AI 标识 | pill + 盾牌图标 | `--mist-100` 底 + `--mist-700` 字，固定文案"AI 生成" |

圆角 `--radius-pill`，高度 20-24px，字号 10-11px / 字重 800，内边距 3px 9px。

- **儿童档案切换器**：顶部下拉 46px + 头像 40px + 添加按钮 40px（移动端热区补足到 44px）。

### 4.6 反馈与状态

- **Toast**：`--shadow-soft` + pill 圆角，图标 + 文案，4 类语义色，3.5s 自动消失，可手动关闭；出现方向顶部居中（桌面）/ 底部上方 88px（移动，避免遮挡底部导航）。
- **内联错误**：表单字段下方，`--danger-bg` 底 + 图标 + 文案；表单顶部另给一条汇总错误（提交失败时）。
- **弹窗 Dialog**：桌面缩放（0.96→1）+ 遮罩 blur 5px，240ms；移动端转为底部上滑抽屉，圆角 24px 24px 0 0，底部留 `env(safe-area-inset-bottom)`。
- **空状态**：插画位（96-112px）+ 衬线标题 + 一句原因 + 一个主行动按钮；四种空态（无记录 / 无提醒 / 无故事 / 无搜索结果）共用同一构成，只换图形与文案。
- **加载态**：骨架屏（1.4s 微光）+ 旋转指示器 + 进度文案（如"已完成 3/8 页"）；AI 流式回答逐字 18-28ms，光标 1s steps(1)，"停止生成"按钮常驻。

### 5.2 间距标尺（4pt 基准）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`——**只允许使用这 9 个值**，禁止 10px、15px、18px 等中间值（现有代码中的 7px、13px 间距需归入标尺）。

### 5.3 首页信息密度节奏（回应"卡片密度偏高"争议）

三档节奏，自上而下密度递增、留白递减：

1. **概览区**（一屏内收）：Hero 卡 326px 高，内边距 28px，与右侧卡 20px 间距——这一区留白最大，只放"今天最该做的一件事"。
2. **列表区**（行高 64px，行间距 10px）：今日提醒 + 最近记录，靠密度换扫描效率。
3. **快捷区**（4 宫格，格高 128-133px，间距 12px）：留白居中，图标块 34px。

规则：**一屏内最多 3 个区块、1 个主行动按钮**。超出则折叠或分页，不靠压缩行高解决。

### 5.4 内容压力规则

- 长内容：标题换行，副标题单行省略，单位/状态不省略。
- 密集数据（生长曲线）：移动端图表高度 220px 固定，X 轴标签隔项显示，提供"查看数据表"入口。
- 空数据：走空状态插画 + 主行动，不用空白卡片占位。

## 8. 响应式行为

### 8.1 断点

| 断点 | 布局变化 |
| --- | --- |
| ≤430px | 快捷入口 2 列；表单双列转单列；弹窗按钮纵向铺满 |

| 1280 / 1440+ | 内容区限宽 1280px 居中；1440+ 不再放大字号，只增左右留白 |

### 8.2 键盘与触摸

- Tab 顺序：品牌 → 主导航 → 页面主行动 → 内容；弹窗打开时焦点移入弹窗并锁定，Esc 关闭后焦点回到触发元素。
- 所有控件 `:focus-visible` 显示 3px 焦点环；深色容器用反白焦点环。
- 触摸热区 ≥ 44×44px，相邻可点区域间距 ≥ 8px；底部导航项高 70px。
- 移动端输入文本 ≥ 16px；时间/日期选择用原生或大尺寸选择器。

### 8.3 加载 / 错误 / 恢复

- 首屏：骨架屏（不闪白），AI 回答用流式逐字而非整块转圈。
- 生成中断：保留已生成内容 + "继续生成" / "重新生成"。
- 上传失败：保留所选文件信息 + 重试按钮，不清空表单。
- 断网：全局横幅 + 页面级错误态，恢复后自动重试一次并提示。

### 8.4 降低动效

`prefers-reduced-motion: reduce` 时所有动画降为 0.01ms，但**保留**状态变化、进度条与流式文本（信息不丢失），只去掉位移、缩放与闪烁。

### 8.5 深色模式结论

**首期不支持全站深色。** 理由：风险四色在深底上需重新验证对比度与色觉可辨性，P0 阶段成本高于收益；当前仅浅色。
**P1 只做「故事阅读页夜间模式」**这一个局部场景（单点、风险可控、场景真实存在——家长夜间陪读）。Token 已按语义化命名，后续做深色只需换语义层，不动组件层。
