# 阶段 3-第 7 阶段前端开发文档：受控入口编排（一句话入口）

## 1. 本阶段目标
- 家长在首页说一句自然语言，系统识别意图（问育儿 / 记成长 / 设提醒 / 讲故事），自动跳到对应页面并预填内容。识别只做"理解 + 路由"，路由后的执行（尤其医疗问答 L1-L4）仍走确定性代码。

## 2. 范围
### 本阶段包含
- 后端：`POST /api/v1/intent/classify` 意图分类接口（LLM 分类 + 槽位抽取，失败兜底 unknown）
- 后端：`intent_service` + `intent_prompt`（五类意图 + 各意图槽位）
- 前端：首页 `IntentBar` 一句话入口（输入 → 分类 → 跳转 + 预填）
- 前端：问育儿页 `?q=` 预填、成长页 `?intent=record/reminder` 预填（事件/提醒 dialog 自动打开）、故事工坊 `?theme=` 预填
- 意图识别失败 / unknown 时：列出四个入口让用户手动选择

### 本阶段不包含
- 相对时间（"半小时后"）解析；语音输入；跨页面多步编排
- 不改变任何医疗安全逻辑（L1-L4 分级、来源引用、免责声明原样保留）

## 3. 用户流程
1. 首页输入"宝宝下午三点要喝奶" → 识别为「设提醒」→ 跳成长页提醒 tab → 弹出提醒框，类型=喂养、标题=喝奶、时间=15:00 已填好
2. 输入"8 个月该打什么疫苗" → 识别为「问育儿」→ 跳问育儿页，问题已预填
3. 输入"给小宝讲个睡前故事" → 识别为「讲故事」→ 跳故事工坊，主题已预填
4. 识别不出 → 列出四个入口让用户点选

## 4. 意图与槽位
| intent | 路由目标 | 抽取槽位 |
|---|---|---|
| ask | /ask?q= | question |
| record | /growth?intent=record&type=&note= | type(六类事件), note |
| reminder | /growth?intent=reminder&type=&title=&note=&time= | type(四类提醒), title, note, time(HH:MM) |
| story | /stories?theme= | theme |
| unknown | 首页列四入口 | — |

## 5. 安全与降级
- 意图分类只做路由，不触发任何医疗/危险动作；识别结果非法值（type/time）在后端归一化兜底
- 模型失败/超时 → 兜底 unknown，入口永远可用
- 意图接口鉴权 + 儿童归属校验（复用 get_owned_child）
