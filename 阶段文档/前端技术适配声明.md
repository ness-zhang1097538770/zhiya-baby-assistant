# 前端技术适配声明

> Kids Mind 育儿多智能体 V1.0 | 阶段 3 正式前端 | 2026-09-17 已确认

## 1. 项目判断
- **产品类型**：0-3 岁育儿助手（问答 + 成长记录 + 提醒 + 数字绘本），含流式问答、长耗时生成（故事）、多媒体产物（插画/音频）。
- **主要用户**：0-3 岁孩子的父母、祖辈，碎片化时间、以手机为主。
- **主要终端**：响应式移动 Web，手机优先，同时支持桌面浏览器验收。
- **新项目或已有项目**：新前端；后端已就绪（阶段 2 完成）。
- **本阶段业务目标**：把已验证的后端能力做成正式产品界面，四条核心链路可用（问答/档案/记录提醒/故事工坊）。

## 3. 技术选择
| 项 | 选择 |
| --- | --- |
| 框架 | Next.js 16.3.5（App Router）+ React 19.2.8 |
| 语言 | TypeScript strict |
| 样式 | Tailwind CSS + CSS 语义变量（温暖亲子的中性方案，先做代表页） |
| 数据请求 | 集中式 API 层 + fetch；MVP 不引入 TanStack Query（请求简单） |
| 状态 | React 自带状态 + URL 参数；不引入 Zustand/Redux |
| 流式 | 问答用 Fetch Streaming（POST SSE）；故事生成用轮询（后端已是任务状态机） |
| 表单 | 原生受控组件（表单简单，不引入 React Hook Form） |
| 测试 | Vitest；核心闭环阶段再加 Playwright |
| 部署 | Next.js standalone（阶段 4 再定） |

## 4. Agent 状态
- 后端故事状态 → 前端统一状态映射：
  `outline_generating→running`、`outline_ready→waiting_user`、`content_generating→running`、`content_ready→waiting_user`、`assets_generating→running`、`ready→succeeded`、`failed→failed`、`cancelled→cancelled`。
- 等待用户确认：大纲确认（可编辑）、生成插画/朗读前的确认。
- 取消：故事生成有后端取消能力（cancel 接口），前端提供"停止生成"。
- 恢复：刷新后按 story id 查后端真实状态恢复；问答会话按 conversation id 恢复历史。

## 5. 页面与产物
- 核心页面（对齐 PRD 一级导航）：
  1. 首页（今日待办/快捷提问/成长摘要/故事入口）
  2. 问育儿（问答 + 会话历史 + 来源引用 + 风险分级）
  3. 成长（儿童档案/时间线/提醒/记录）
  4. 故事工坊（角色/主题/生成/书架/朗读）
  5. 我的（家庭成员/隐私授权/通知/账户）
- 核心业务闭环：①提问→流式 CARE 答案→来源；②建档→记录→时间线→提醒；③故事→大纲确认→正文→插画+朗读→书架。
- 产物类型：文本（CARE 答案）、图片（插画）、音频（朗读 mp3）。
- 响应式目标：390 / 768 / 1280 / 1440。

## 6. 偏离本手册的地方
| 偏离项 | 原因 | 影响 |
| --- | --- | --- |
| 暂缓 TanStack Query / Zustand | MVP 请求与状态简单，先用 React 自带能力 | 无，后续需要时再引入 |
| 暂缓 React Hook Form | 表单均为简单受控输入 | 无 |
| 语音输入暂缓 | 后端 ASR 未做（阶段 3 暂缓项） | 问答先文本为主 |
| 生产构建用 webpack | 当前本机沙箱禁止 Turbopack CSS 编译器临时绑定端口 | 不改变产物功能，上线前可在部署环境复验 Turbopack |
