# 阶段 3 第 6 阶段前端开发文档

> Kids Mind 正式前端·我的页（儿童档案 + 隐私说明 + 关于） | 2026-09-18

## 1. 本阶段目标
完成「我的」页，展示儿童档案列表、隐私与数据说明、版本与免责声明，补齐正式前端五个一级页面的最后一块。

## 2. 范围

### 包含
- `/profile` 我的页：儿童档案列表（真实后端）、添加孩子（复用 ChildDialog）。
- 隐私与数据说明：数据留国内、敏感信息不训练、提醒本地触发。
- 关于：版本 v1.0（内部试用版）、免责声明、危急情况提示。

### 不包含
- 儿童档案编辑/删除（后端无更新/删除接口，页面如实标注"暂未开放"）。
- 家庭成员管理、隐私授权开关、账户/邀请码登录（后端无会话接口，属阶段 4 后续）。
- 数据导出/删除（D6 要求，后端待补）。

## 3. 页面结构
1. 头部「我的」。
2. 儿童档案：列表 + 添加孩子。
3. 隐私与数据：三条说明。
4. 关于：版本 + 免责声明。

## 4. 接口契约
- `GET /api/v1/children`：儿童列表。
- `POST /api/v1/children`：建档（复用 ChildDialog）。
- 无其他后端改动。

## 5. 实现方案
- 组件：`ProfilePage`（客户端组件，加载儿童列表 + 静态文案）。
- 响应式：桌面 720px 单列卡片，移动端自适应；无横向溢出。

## 6. 验收标准
- lint / typecheck / test / build 全过。
- 后端 mock 回归 36/36。
- 390/768/1280/1440px 无横向溢出。
