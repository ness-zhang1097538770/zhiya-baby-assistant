# 阶段 3 第 4 阶段前端开发文档

> Kids Mind·App 封装 + 到点响铃提醒（安卓内测） | 2026-09-18

## 1. 本阶段目标
把网页版 Kids Mind 封装成安卓 App，并接入系统本地通知，让「提醒」从"列表数据"变成"到点像闹钟一样弹提醒 + 响铃"，App 关掉、锁屏也能触发。

## 2. 范围

### 包含
- Capacitor 封装安卓工程（appId com.kidsmind.app，appName Kids Mind）。
- `@capacitor/local-notifications` 本地通知：按提醒时间排程、取消、权限申请。
- 前端通知桥 `lib/notifications.ts`：纯 web 环境下静默降级（不报错），原生环境调用插件。
- 提醒联动：新建/编辑后按新时间排程，停用/删除后取消，加载时全量对账。
- 安卓 APK 构建产物（debug 内测包）。

### 不包含
- iOS 封装（Apple 开发者账号 688/年，产品经理暂缓）。
- 独立离线运行（当前内测包加载电脑开发服务器，需同一 WiFi + ./start.sh）。
- 真实推送（服务端 Web Push）、App 商店上架。

## 3. 用户流程
1. 手机装 APK → 打开 Kids Mind → 加载电脑上的页面（同一 WiFi）。
2. 成长 → 提醒 → 添加提醒（时间设为未来）→ 保存时允许通知权限。
3. 到点手机弹通知 + 响铃；停用/删除后不再触发；关 App、锁屏仍按时触发。

## 4. 通知排程逻辑
- 纯函数 `reminderNotificationDecision(reminder, now)`：`enabled && 未来时间` 才排程，否则取消；非法时间不排程。
- 通知 id 直接复用后端 reminder.id（一一对应，便于取消/覆盖）。
- `allowWhileIdle: true` + `SCHEDULE_EXACT_ALARM` 权限声明，尽量精确到点。

## 5. 接口契约
- 无后端改动；提醒数据仍走既有 `POST/PUT/DELETE /api/v1/.../reminders`。
- 通知只在本机由系统触发，提醒内容不上传第三方。

## 6. 实现方案
- 技术栈：Capacitor 8 + @capacitor/local-notifications 8 + Android SDK 36 + Gradle 8.14.3 + JDK 21。
- 内测加载方式：`capacitor.config.ts` 的 `server.url` 指向开发服务器（`http://<局域网IP>:3001`，cleartext），`/api` 由开发服务器同源代理到后端。
- 通知桥：运行时检测 `window.Capacitor.isNativePlatform()`，原生才动态 import 插件；web 环境全部 no-op。

## 7. 验收标准
- 前端单测（通知排程 4/4）、lint、typecheck、web build 全过。
- `./gradlew assembleDebug` 产出可安装 APK。
- 真机（产品经理安卓手机）：到点响铃、停用/删除不响、锁屏仍响。

## 8. 风险与回退
- 风险：`server.url` 依赖电脑 IP 与 `./start.sh`，IP 变化需改配置重打包。处理：阶段 4 上线时改为静态打包 + 可配置后端地址，脱离开发服务器。
- 风险：Android 12+ 精确闹钟需系统「闹钟与提醒」授权，未授权时可能略有偏差。处理：安装说明里提示。
- 回退：本阶段为纯新增（android/ 目录 + 通知桥），不改动 web 既有功能；去掉通知桥即可回到纯 web。
