# 阶段 3 第 1 阶段前端开发文档

> Kids Mind 正式前端·可运行骨架与首页代表页 | 2026-09-17

## 1. 本阶段目标
家长用手机或电脑打开 Kids Mind 后，可以看到一个正式产品级首页，切换真实儿童档案，查看来自后端的提醒、成长记录和故事入口。

## 2. 范围

### 包含
- Next.js App Router + TypeScript strict + Tailwind CSS 工程骨架。
- 桌面侧边导航和手机底部导航。
- 首页代表页：孩子切换、今日照护、快捷记录、最新成长记录、故事入口。
- 真实后端联调：儿童列表、近 7 天提醒、成长记录、故事书架。
- 无档案空状态和创建儿童档案弹窗，创建后使用真实 API 持久化。
- 加载、空数据、后端断开与重试状态。
- 问育儿、成长、故事、我的占位路由，明确标注下一子阶段接入，不冒充完成。

### 不包含
- 问育儿 SSE 流式闭环、成长记录编辑、故事长任务交互：待代表页视觉确认后逐项铺开。
- 邀请码登录：后端尚无会话接口，不做前端假登录。
- 语音输入、消息推送和原生 App 封装。

## 3. 用户流程
1. 打开首页，前端从后端读取儿童档案。
2. 有档案时自动恢复上次选中的孩子，无档案时引导建档。
3. 并行读取该孩子的提醒、成长记录和故事。
4. 用户切换孩子后，重新读取真实数据并保存本机偏好。
5. 用户可进入各业务路由；未实现的路由如实告知后续接入。

## 5. 接口契约
- `GET /api/v1/children`：获取儿童列表。
- `POST /api/v1/children`：创建儿童档案，必填昵称和出生日期。
- `GET /api/v1/children/{id}/reminders/upcoming?days=7`：获取未来 7 天提醒。
- `GET /api/v1/children/{id}/events`：获取成长记录。
- `GET /api/v1/children/{id}/stories`：获取书架。
- 所有请求统一经 `lib/api.ts` 设置 12 秒超时、安全错误转换和同源代理；前端不包含任何密钥。

## 6. 实现方案
- 路由：`/`、`/ask`、`/growth`、`/stories`、`/profile`。
- 响应式：390px 手机使用底部导航，桌面使用固定侧边栏；768px 与 1080px 附近重排卡片。
- 状态：后端数据是最终事实来源；Local Storage 只保存非关键的 child id 偏好。
- 安全：同源 `/api/*` 代理到 FastAPI；不把 Key、模型配置或完整文档写入浏览器。

## 7. 验收标准
- `npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 全部通过。
- FastAPI mock 回归测试通过。
- 在 390 / 768 / 1280 / 1440px 宽度检查首页，无横向滚动，导航和主要操作可见。
- 真实前端从 `127.0.0.1:8001` 后端读取儿童列表。
- 代表页视觉需产品经理确认后，再铺开全站。

## 8. 风险与回退
- 风险：当前后端无登录/家庭隔离接口。处理：本地内测先联调功能，不把当前状态宣布为可上线。
- 风险：Turbopack 在当前沙箱因临时端口权限崩溃。处理：生产构建使用 Next.js 官方 webpack 模式，已通过。
- 回退：新前端为独立 `frontend/` 目录，未替换后端的旧验收界面。
