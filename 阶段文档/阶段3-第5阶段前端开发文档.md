# 阶段 3 第 5 阶段前端开发文档

> Kids Mind 正式前端·故事工坊（书架 + 生成流程 + 阅读器） | 2026-09-18

## 1. 本阶段目标
家长在「故事」页选中孩子后，可以创作专属绘本：选主角与主题 → AI 生成大纲（可编辑确认）→ 生成正文 → 生成插画与朗读 → 在书架阅读（翻页 + 朗读）。

## 2. 范围

### 包含
- `/stories` 书架页：孩子选择器、故事卡片（封面/占位图 + 状态徽标）、创作表单。
- `/stories/[id]` 故事详情页，按状态渲染：
  - 生成中（大纲/正文/插画朗读）：进度提示 + 2.5 秒轮询 + 「停止生成」。
  - outline_ready：大纲确认（可改标题与每页内容）→ 确认并生成正文。
  - content_ready：正文逐页预览 → 生成插画和朗读。
  - ready：阅读器（插画 + 正文 + 翻页 + 朗读播放）。
  - failed / cancelled：失败/取消态。
- 故事创建表单（主角名、性别、主题、月龄、篇幅、教育目标、家庭记忆）。

### 不包含
- 插画风格选择（后端未暴露风格参数，后续补）。
- 故事编辑回退到前一步（当前只前进、可停止）。
- 语音输入、分享。

## 3. 用户流程
1. 打开故事页 → 书架（或空状态）。
2. 点「创作故事」填主角与主题 → 创建 → 进入故事详情，等待大纲生成。
3. 大纲就绪后确认（可编辑）→ 等待正文生成。
4. 正文就绪后点「生成插画和朗读」→ 等待资产生成。
5. 完成后进入阅读器翻页 + 朗读；书架展示状态徽标。

## 4. 页面状态矩阵
| 状态 | 展示 |
| --- | --- |
| outline_generating / content_generating / assets_generating | 进度提示 + 轮询 + 停止生成 |
| outline_ready | 大纲编辑器 + 确认并生成正文 |
| content_ready | 正文预览 + 生成插画和朗读 |
| ready | 阅读器 |
| failed | 错误信息 + 回书架 |
| cancelled | 已取消 + 回书架 |

## 5. 接口契约
- `GET /api/v1/children/{id}/stories`：书架列表。
- `POST /api/v1/children/{id}/stories`：创建，后台生成大纲。
- `GET /api/v1/stories/{id}`：详情（轮询用）。
- `POST /api/v1/stories/{id}/confirm`：确认大纲（可带编辑后大纲）。
- `POST /api/v1/stories/{id}/assets`：生成插画/朗读。
- `POST /api/v1/stories/{id}/cancel`：停止生成。
- `DELETE /api/v1/stories/{id}`：软删除。
- 资产 URL 为 `/story_assets/{story_id}/page_{n}.png|.mp3`，经同源代理访问。

## 6. 实现方案
- 组件：`StoriesPage`（书架 + 创建）→ `StoryCreateDialog`（表单）、`StoryDetailPage`（状态机视图 + 阅读器）。
- 状态：后端是事实来源；生成中状态用 `setInterval` 2.5 秒轮询 `getStory`。
- 阅读器：单页展示，`<audio>` 播放该页朗读，翻页时切换图片与音频。
- 导航：创建成功用 `useRouter().push()` 进入详情页。
- 响应式：书架网格 390px 双列 / 桌面自适应；阅读器单列。

## 7. 验收标准
